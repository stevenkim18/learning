예제의 모델명은 gpt-5.4-mini야. 실제 호출 전에 내 계정에서 사용할 수 있는 모델인지 확인해 줘.

코드는 복사하거나 파일 저장 버튼으로 내려받아 터미널에서 실행해. 실제 모델을 호출하는 예제는 API 키와 인터넷 연결이 필요하고 사용 요금이 발생할 수 있어.

이번 강의에서는 LangChain의 문법을 외우는 것보다 왜 LangChain이 필요하고, 우리가 무엇을 만들 수 있는지 이해하는 데 집중할 거야.

실습도 포함할 거야. 아직 LangChain을 설치하지 않았으므로 먼저 순수 Python으로 작동 원리를 체험한 뒤, 실제 LangChain 코드가 어떻게 생겼는지도 살펴보자.

01

LangChain이란?

1-1. 한 문장으로 이해하기

LangChain은 LLM을 애플리케이션의 데이터, 도구, 로직과 연결해서 AI 기능을 개발할 수 있도록 도와주는 Python 및 JavaScript 기반 프레임워크야.

여기서 LLM은 Large Language Model, 즉 대규모 언어 모델을 뜻해.

예를 들면 다음과 같은 모델들이 있어.

  • OpenAI의 GPT 모델
  • Anthropic의 Claude 모델
  • Google의 Gemini 모델
  • 오픈소스 Llama 계열 모델

이 모델들이 AI의 두뇌라면, LangChain은 AI가 실제 프로그램 안에서 일할 수 있도록 구성하는 연결 장치이자 실행 구조라고 생각하면 돼.

LangChain 자체가 AI 모델을 학습시키는 것은 아니야. 기존 모델을 활용해서 원하는 서비스를 구현하도록 도와주는 도구라고 이해하면 정확해.

02

LangChain은 왜 필요할까?

가령 Python으로 AI 챗봇을 만든다고 생각해 보자.

가장 단순한 프로그램은 다음과 같이 작동해.

이 정도는 LangChain 없이 OpenAI 공식 Python SDK만으로도 충분히 만들 수 있어.

그런데 조금 더 복잡한 서비스를 만든다면?

예를 들어 다음과 같은 요구사항이 생길 수 있어.

  1. 사용자의 질문을 분석한다.
  2. 우리 회사의 문서에서 관련 내용을 찾는다.
  3. 필요한 경우 외부 API나 데이터베이스를 조회한다.
  4. 검색한 정보를 LLM에 전달한다.
  5. 답변을 정해진 JSON 형식으로 만든다.
  6. 실행 과정의 오류와 비용을 추적한다.

이런 상황에서 LangChain을 활용하면 모델 호출, 도구 연결, 출력 처리 등을 일관된 인터페이스로 구성할 수 있어.

다만 LangChain이 모든 서비스를 더 간단하게 만드는 것은 아니야. 단순히 LLM을 한 번 호출하는 프로그램이라면 공식 SDK만 사용하는 편이 더 가벼울 수도 있어.

2-1. LangChain 없이 개발할 때와 비교

구분공식 LLM SDK만 사용LangChain 활용
단순 AI 호출매우 적합가능
프롬프트 관리직접 구현템플릿 제공
여러 모델 연결SDK별로 구현공통 인터페이스 지원
외부 도구 호출직접 연결 로직 작성도구 및 에이전트 API 제공
RAG 구축필요한 구성 요소 직접 연결관련 구성 요소 및 통합 제공

핵심: LangChain은 AI를 더 똑똑하게 만드는 마법이 아니라, AI를 활용하는 소프트웨어를 개발하기 쉽게 도와주는 프레임워크야.

03

LangChain의 핵심 구성 요소

LangChain을 공부할 때 처음부터 모든 기능을 외울 필요는 없어.

우선 아래 6가지 개념을 익혀두면 앞으로의 강의가 훨씬 쉬워질 거야.

기본 모델 호출 흐름을 단순화한 그림이야. 도구, 검색, 에이전트 등을 추가하면 구조가 확장돼.

3-1. Model — AI 모델

Model은 실제로 질문을 이해하고 답변을 생성하는 AI야.

LangChain에서는 모델 공급자마다 다른 API를 사용하더라도, 가능한 한 공통된 방식으로 호출하도록 도와줘.

예를 들어 다음과 같은 코드를 사용할 수 있어.

Python
model = ChatOpenAI(model="gpt-5.4-mini")response = model.invoke("안녕!")

지금은 실행하지 않아도 돼.

여기서는 두 가지만 기억하자.

ChatOpenAI()는 OpenAI의 채팅 모델을 사용하기 위한 객체를 만들고, invoke()는 모델에 입력을 전달하고 응답을 받는 메서드야. 모델 사용법 ↗ChatOpenAI ↗

3-2. Prompt — AI에게 주는 지시문

Prompt(프롬프트)는 AI에게 전달하는 질문이나 명령이야.

예를 들어 다음 두 프롬프트를 비교해 보자.

일반적인 프롬프트

파이썬 설명해 줘.

구체적인 프롬프트

너는 Python 전문 강사야. 프로그래밍 초보자에게 파이썬을 3문장으로 쉽게 설명하고, 일상생활의 비유를 하나 포함해 줘.

두 번째처럼 AI에게 역할과 출력 조건을 명확하게 알려줄 수 있어.

LangChain에는 이러한 프롬프트를 재사용할 수 있도록 만드는 ChatPromptTemplate 기능이 있어. 이 부분은 2-6강에서 자세히 학습할 거야.

3-3. Chain — 처리 단계를 연결하기

LangChain 이름에 들어가는 Chain은 영어로 '사슬'이라는 의미야.

프로그래밍에서는 여러 처리 단계를 연결하는 개념으로 이해하면 좋아.

예를 들어 다음과 같은 작업이 있다고 생각해 보자.

예상 결과 / 흐름
프롬프트 생성     ↓AI 모델 호출     ↓응답을 문자열로 변환     ↓결과 출력

LangChain에서는 이러한 단계를 | 연산자로 연결할 수 있어.

Python
chain = prompt | model | output_parser

이 문장은 다음 의미야.

프롬프트의 결과를 모델에 전달하고, 모델의 응답을 출력 처리기에 전달한다는 뜻이야.

이 방식을 LCEL(LangChain Expression Language)이라고 불러.

다만 모든 AI 프로그램이 반드시 Chain으로 구성되어야 하는 건 아니야. 간단한 프로그램에서는 모델을 직접 호출해도 돼.

3-4. Tool — AI가 사용하는 도구

LLM은 기본적으로 학습된 지식과 입력된 정보를 활용해서 답변해.

하지만 실제 서비스를 만들 때는 외부 기능이 필요할 수 있어.

예를 들어 AI에게 현재 데이터베이스의 사용자 수를 물어본다고 생각해 보자.

이때 AI는 실제 데이터베이스를 조회할 수 있는 기능이 필요해.

LangChain에서는 Python 함수나 외부 서비스를 AI가 사용할 수 있는 Tool(도구)로 연결할 수 있어.

Python
def get_user_count():    return 120

이 함수는 항상 숫자 120을 반환하는 연습용 코드야. 실제로 데이터베이스를 조회하는 것은 아니야.

나중에는 이 부분을 실제 DB 조회 함수로 변경할 수 있어.

3-5. Agent — AI가 도구를 선택하는 실행 구조

Agent(에이전트)는 AI 모델이 필요한 도구를 선택하고 사용하면서 작업을 수행하도록 만드는 구조야.

Chain과 Agent의 차이를 이해해 보자.

예를 들어 사용자가 다음과 같이 요청했다고 해보자.

"오늘 신규 가입자 수를 확인하고, 지난주 평균과 비교해서 보고서를 만들어 줘."

에이전트는 제공된 도구들을 활용해 데이터를 조회하고, 필요한 계산을 수행하고, 결과를 정리하도록 구성할 수 있어.

최신 LangChain에서 에이전트를 만드는 대표적인 API가 create_agent()야. 공식 개요 ↗에이전트 ↗

3-6. RAG — 외부 문서를 검색해 답변하기

RAG는 Retrieval-Augmented Generation, 한국어로는 검색 증강 생성이라고 불러.

쉽게 말하면 AI가 답변하기 전에 관련 자료를 검색해서 참고하도록 하는 기술이야.

예를 들어 우리 회사에서 사용하는 100페이지짜리 업무 매뉴얼이 있다고 해보자.

사용자가 "우리 회사의 휴가 신청 절차는 어떻게 돼?"라고 질문하면 다음과 같은 흐름으로 작동하는 시스템을 만들 수 있어.

RAG를 사용한다고 해서 반드시 정답이 보장되지는 않지만, LLM이 외부의 관련 자료를 참고하도록 만들어 답변의 근거를 강화할 수 있어.

04

LangChain, LangGraph, LangSmith 차이

LangChain을 공부하다 보면 비슷한 이름들이 등장할 거야.

이름이 비슷해도 역할은 조금씩 달라.

기술역할비유
LangChain모델, 도구, 에이전트 등을 구성AI 개발 도구 상자
LangGraph상태와 분기가 있는 복잡한 워크플로 제어AI 작업 흐름 설계도
LangSmith실행 추적, 디버깅, 평가AI 실행 기록 및 분석 도구

최신 공식 문서에서도 이러한 역할 구분을 사용하고 있어. 공식 개요 ↗

처음에는 LangChain의 모델 호출과 프롬프트부터 배우고, 이후 에이전트와 LangGraph로 넘어가면 돼.

또한 인터넷의 오래된 강의에는 LLMChain이라는 클래스가 자주 나오는데, 현재는 deprecated(사용 중단 권장) 상태야. 우리는 새로운 Runnable 인터페이스와 create_agent() 중심으로 학습할 거야. LLMChain 참고 ↗

5-3. 코드 한 줄씩 해설

첫 번째: 프롬프트를 만드는 함수

Python
def make_prompt(topic):    return f"{topic}에 대해 초보자에게 쉽게 설명해 줘."

def는 함수를 정의할 때 사용하는 키워드야.

make_prompt는 우리가 만든 함수 이름이야.

topic은 외부에서 전달받는 매개변수야.

f"..."는 f-string이라는 Python 문법인데, {topic} 자리에 변수의 값을 넣어 줘.

예를 들어 다음 코드를 실행하면,

Python
print(make_prompt("랭체인"))

topic = input("공부할 주제를 입력하세요: ")

input()은 사용자에게 문자열을 입력받는 Python 기본 함수야.

예를 들어 사용자가 랭체인을 입력하면 변수 topic에는 "랭체인"이라는 문자열이 저장돼.

네 번째: 함수들을 순서대로 호출하기

Python
prompt = make_prompt(topic) answer = fake_model(prompt)

여기가 이번 실습에서 가장 중요한 부분이야.

첫 번째 함수의 반환값이 두 번째 함수의 입력으로 사용되고 있어.

예상 결과 / 흐름
topic  ↓make_prompt(topic)  ↓prompt  ↓fake_model(prompt)  ↓answer

LangChain에서도 이러한 데이터 전달과 단계 연결이 중요한 개념이야.

다섯 번째: 결과 출력

Python
print("생성된 프롬프트:", prompt)print("AI 응답:", answer)

print()는 값을 화면에 출력하는 기본 함수야.

여기까지 완성했다면 우리가 만든 작은 AI 처리 흐름이 어떻게 작동하는지 이해한 거야.
