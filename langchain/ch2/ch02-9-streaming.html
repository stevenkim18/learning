01

최종 응답과 스트리밍 비교하기

invoke()는 호출이 끝나면 AIMessage를 반환해. stream()은 반복하면서 AIMessageChunk라는 응답 조각을 받을 수 있게 해 줘.

방식호출 예시받는 것
동기 최종 응답model.invoke(question)AIMessage 하나
비동기 최종 응답await model.ainvoke(question)AIMessage 하나
동기 스트리밍for chunk in model.stream(question)여러 AIMessageChunk
비동기 스트리밍async for chunk in model.astream(question)여러 AIMessageChunk

스트리밍은 첫 내용을 먼저 보여주는 방법이야. 전체 답변의 생성 시간이 반드시 더 짧아진다는 뜻은 아니야. 비동기와 스트리밍도 서로 다른 개념이야. 최종 결과를 기다리는 비동기 호출도 있고, 동기 방식으로 읽는 스트림도 있어.

02

청크는 정확히 무엇일까?

Chunk는 나누어진 조각이라는 뜻이야. AIMessageChunk에는 텍스트뿐 아니라 응답 메타데이터나 사용량 정보도 들어갈 수 있어.

청크 하나가 항상 글자 하나나 토큰 하나인 것은 아니야. 빈 문자열, 여러 글자, 텍스트가 없는 마지막 사용량 청크가 올 수도 있어.

예상 결과 / 흐름
받은 조각: "파이" → "썬은 " → "언어야." → ""화면 출력: 파이썬은 언어야.

이 글자 나눔은 설명을 위한 예시야. 실제 분할 위치는 모델과 호출 조건에 따라 달라져.

이번 강의에서는 chunk.text로 읽을 수 있는 텍스트를 출력해. chunk.content는 공급자와 응답 형식에 따라 문자열 또는 콘텐츠 블록 리스트일 수 있어. 텍스트 이외의 정보와 텍스트 출력은 구분하자.

공식 참고: 메시지 공식 문서 ↗

03

Python의 for와 print() 복습

for는 반복 가능한 대상에서 값을 하나씩 꺼내. 스트림도 반복하며 청크를 받을 수 있어.

Python
parts = ["안녕", "하세요", "!"]for text in parts:    print(text, end="", flush=True)print()

예상 출력:

예상 결과 / 흐름
안녕하세요!
부분의미
for text in parts다음 문자열을 하나씩 가져옴
end=""매번 출력할 때 줄바꿈하지 않음
flush=TruePython의 출력 버퍼를 바로 비우도록 요청
마지막 print()답변이 끝난 뒤 한 번 줄바꿈

실제 출력의 즉시성은 사용하는 터미널이나 노트북 환경에도 영향을 받아. flush=True가 네트워크 응답 생성 자체를 빠르게 만드는 것은 아니야.

04

실습 ① API 없이 청크 출력하기

먼저 실제 모델을 부르지 않고 동작 원리를 연습하자. stream_demo.py 파일을 만들어.

stream_demo.py
파일 저장 ↓
from langchain_core.messages import AIMessageChunk, message_chunk_to_message chunks = [    AIMessageChunk(content="파이썬은 "),    AIMessageChunk(content="배우기 쉬운 "),    AIMessageChunk(content="프로그래밍 언어야."),    AIMessageChunk(content="", usage_metadata={        "input_tokens": 10, "output_tokens": 5, "total_tokens": 15    }),] full = Noneprint("연습 응답: ", end="", flush=True)for chunk in chunks:    if chunk.text:        print(chunk.text, end="", flush=True)    full = chunk if full is None else full + chunkprint() if full is not None:    message = message_chunk_to_message(full)    print("완성 타입:", type(message).__name__)    print("완성 내용:", message.content)    print("연습용 사용량:", message.usage_metadata)
터미널
uv run python stream_demo.py

예상 출력:

예상 결과 / 흐름
연습 응답: 파이썬은 배우기 쉬운 프로그래밍 언어야.완성 타입: AIMessage완성 내용: 파이썬은 배우기 쉬운 프로그래밍 언어야.연습용 사용량: {'input_tokens': 10, 'output_tokens': 5, 'total_tokens': 15}

사용량 숫자는 직접 만든 연습용 데이터야. 이 코드는 API를 호출하지 않아. 따라서 표시된 숫자는 실제 사용량이나 과금 내역이 아니야.

05

실습 ① 코드 한 줄씩 해설

코드의미
AIMessageChunk응답 조각을 표현하는 클래스 가져오기
chunks = [...]연습용 청크를 리스트로 준비
full = None아직 모은 응답이 없다는 초기 상태
if chunk.text출력할 텍스트가 있는지 확인
print(..., end="", flush=True)내용을 이어서 바로 출력
full = chunk if ... else full + chunk첫 청크로 시작하고 이후 청크를 더함
message_chunk_to_message(full)모은 청크를 일반 메시지 객체로 변환
message.usage_metadata합쳐진 메시지의 사용량 정보 확인

+는 여기서 단순히 두 객체를 문자열처럼 붙이는 문법만은 아니야. LangChain 메시지 청크의 결합 동작을 사용해 텍스트와 지원되는 메타데이터를 함께 모아.

화면에 출력할 텍스트가 없어도 마지막 청크를 무조건 버리면 메타데이터를 놓칠 수 있어. 위 코드는 출력 여부와 청크 합치기를 따로 처리해.

06

실습 ② 실제 ChatOpenAI 스트리밍

이번 실습은 실행하면 실제 모델 요청을 보내. .env에 본인의 API 키가 설정되어 있어야 해. 브라우저의 HTML 기능은 이 코드를 실행하지 않아.

stream_llm.py 파일을 만들어.

stream_llm.py
파일 저장 ↓
import osfrom pathlib import Pathfrom dotenv import load_dotenvfrom langchain_openai import ChatOpenAIfrom langchain_core.messages import message_chunk_to_messagefrom openai import APIError load_dotenv(Path(__file__).resolve().parent / ".env")api_key = os.getenv("OPENAI_API_KEY")if not api_key or api_key == "put_your_real_api_key_here":    raise RuntimeError("OPENAI_API_KEY를 설정해 주세요.") model = ChatOpenAI(    model="gpt-5.4-mini", stream_usage=True,    timeout=30, max_retries=1, max_tokens=300)question = "Python의 함수를 초보자에게 2문장으로 설명해 줘."full = Nonecompleted = False print("AI: ", end="", flush=True)try:    for chunk in model.stream(question):        if chunk.text:            print(chunk.text, end="", flush=True)        full = chunk if full is None else full + chunk    completed = Trueexcept APIError as error:    print("\n응답을 끝까지 받지 못했습니다:", type(error).__name__)finally:    print() if completed and full is not None:    message = message_chunk_to_message(full)    print("응답 타입:", type(message).__name__)    print("사용량:", message.usage_metadata)elif completed:    print("응답 청크를 받지 못했습니다.")
터미널
uv run python stream_llm.py

응답 문장, 청크 수와 사용량은 실제 호출마다 달라질 수 있어. 위 예제에는 실제 모델을 호출해 얻은 답변을 고정 정답처럼 넣지 않았어.

07

실습 ② 핵심 코드 해설

stream_usage=True는 OpenAI 연동에서 스트리밍 사용량 정보를 받도록 설정하는 옵션이야. 실제 정보 제공 여부는 사용하는 API와 호환성 설정에도 영향을 받을 수 있어.

model.stream(question)을 반복하면서 조각을 받아. chunk.text는 텍스트 출력에, full + chunk는 완성 메시지를 모으는 데 사용해.

completed는 정상적으로 반복을 끝냈는지 기록하는 불리언 변수야. 예외로 중단된 경우 이미 화면에 일부 문장이 보였더라도 완성 답변으로 확정하지 않아.

APIError는 OpenAI SDK의 API 관련 오류를 다루는 기본 예외 클래스야. 예외의 클래스 이름만 출력하고 실제 키를 출력하지 않아. 인증·사용량·연결 문제는 원인에 맞게 해결해야 해.

timeout, max_retries, max_tokens는 대기·재시도·출력에 관한 설정이야. 짧은 응답을 연습하기 위한 값이며, 오류가 있었다고 사용량이 항상 0이라고 단정하면 안 돼.

GPT-5 계열처럼 추론하는 모델은 화면에 보이지 않는 추론 토큰도 max_tokens 한도에 포함돼. 답변이 비어 있거나 중간에 끊기면 이 값을 늘려 봐.

08

실습 ③ async for와 astream()

ainvoke()는 await해서 최종 결과 하나를 받아. 반면 astream()은 비동기 이터레이터이므로 async for로 조각을 받아.

async_stream_llm.py 파일을 만들어.

async_stream_llm.py
파일 저장 ↓
import asyncioimport osfrom pathlib import Pathfrom dotenv import load_dotenvfrom langchain_openai import ChatOpenAI async def main():    load_dotenv(Path(__file__).resolve().parent / ".env")    key = os.getenv("OPENAI_API_KEY")    if not key or key == "put_your_real_api_key_here":        raise RuntimeError("OPENAI_API_KEY를 설정해 주세요.")     model = ChatOpenAI(model="gpt-5.4-mini", timeout=30, max_retries=1)    print("AI: ", end="", flush=True)    async for chunk in model.astream("리스트를 2문장으로 설명해 줘."):        if chunk.text:            print(chunk.text, end="", flush=True)    print() if __name__ == "__main__":    asyncio.run(main())
터미널
uv run python async_stream_llm.py
코드해설
async def main()비동기 진입점 정의
async for ... in model.astream(...)다음 청크를 기다리는 동안 다른 코루틴이 진행할 수 있음
chunk.text받은 조각의 텍스트
asyncio.run(main()).py 파일에서 비동기 함수를 실행

async for chunk in await model.astream(...)처럼 전체 스트림 객체에 await를 붙이지 않아. 노트북처럼 이미 이벤트 루프가 실행 중이면 최상위에서 await main()을 사용하는 방식이 필요할 수 있어.

09

LCEL 체인도 스트리밍할 수 있을까?

가능해. 다음은 환경변수를 불러오고 model을 이미 만든 상태에서 사용하는 핵심 코드야.

Python
from langchain_core.prompts import ChatPromptTemplatefrom langchain_core.output_parsers import StrOutputParser prompt = ChatPromptTemplate.from_messages([    ("system", "너는 친절한 Python 선생님이야."),    ("human", "{topic}에 대해 2문장으로 설명해 줘.")])chain = prompt | model | StrOutputParser() for text in chain.stream({"topic": "딕셔너리"}):    print(text, end="", flush=True)print()

체인이 StrOutputParser()로 끝나므로 여기서 받는 값은 문자열이야. text.content를 사용하지 말고 문자열 자체를 출력해.

반대로 prompt | model로 끝나면 모델의 메시지 청크를 받아. 응답 형태는 체인의 마지막 단계가 무엇인지에 따라 달라져.

다른 중간 단계가 입력 전체를 모아야만 결과를 만들면 이후 단계의 스트리밍 시작이 늦어질 수 있어. |를 썼다고 모든 단계가 항상 같은 방식으로 조각을 전달하는 것은 아니야.

공식 참고: Runnable 문서 ↗ · StrOutputParser 문서 ↗

10

응답과 사용량을 함께 보관하기

텍스트만 문자열로 합치면 메시지 메타데이터는 보관되지 않아. 답변 글자만 필요할 때는 간단하지만, 사용량과 종료 정보도 필요하면 청크 자체를 모으는 방식을 고려하자.

Python
full = Nonefor chunk in model.stream(question):    full = chunk if full is None else full + chunk if full is not None:    print(full.text)    print(full.usage_metadata)

이 코드는 기존 model, question이 있는 상태의 부분 예제이며 실제 모델 요청이 발생해. usage_metadata가 None이면 사용량 정보를 못 받은 것으로 처리하자. 토큰 수나 비용이 0이라고 확정하는 것은 아니야.

자주 발생하는 오류와 해결

증상원인과 확인할 점
청크마다 줄바꿈print()의 end="" 확인
한꺼번에 보임출력 버퍼와 실행 환경 확인 · flush=True 사용
str에는 content가 없음StrOutputParser 뒤의 결과를 메시지처럼 다루지 않았는지 확인
async_generator를 await할 수 없음astream()은 async for로 읽기
빈 청크가 나옴메타데이터 전용 조각일 수 있음 · 텍스트가 없어도 합치기는 진행
중간에 연결이 끊김부분 결과임을 알리고 완성 응답으로 저장하지 않기
사용량이 없음stream_usage 설정과 API 호환성 확인

인증과 사용량 제한 오류는 앞 강의에서 배운 원인 확인 절차를 사용해. 실제 키를 화면 공유나 로그에 출력해서 확인하지 않아.
