01

동기와 비동기란?

1-1. 동기(Synchronous)

동기는 하나의 작업이 끝날 때까지 기다린 뒤 다음 작업을 실행하는 방식이야.

예를 들어 세 개의 AI 요청이 각각 2초씩 걸린다고 가정해 보자.

동기 방식 — 순차 실행 예시

총 약 6초 (가정한 요청 시간만 계산)

요청 A가 끝나면 B를 실행하고, B가 끝나면 C를 실행하는 거야.

1-2. 비동기(Asynchronous)

비동기 방식에서는 작업이 외부 응답을 기다리는 동안 다른 작업을 진행할 수 있어.

비동기 방식 — 동시 실행 예시

총 약 2초 (동시 처리할 수 있다고 가정)

세 요청이 모두 약 2초 걸리고, 외부 서버가 동시에 처리해 줄 수 있다면 전체 대기 시간을 줄일 수 있어.

다만 실제 실행 시간은 네트워크, 서버 부하, 요청 제한 등에 따라 달라질 수 있어.

1-3. 일상생활 비유

라면을 끓이고 세탁기를 돌리는 상황을 생각해 보자.

동기 방식이라면 세탁기가 끝날 때까지 기다렸다가 라면을 끓이는 모습에 가까워.

비동기 방식이라면 세탁기를 작동시켜 놓고 세탁기가 돌아가는 동안 라면을 끓일 수 있겠지.

핵심은 기다리는 시간을 다른 작업에 활용하는 것이야.

Python의 asyncio는 여러 작업이 대기 지점에서 실행 기회를 양보하는 협력적 동시성을 제공해. 이것이 곧 CPU 코드를 여러 코어에서 병렬로 실행한다는 의미는 아니야. 공식 문서 ↗

02

async, await, asyncio 이해하기

Python 비동기를 배우려면 우선 세 가지 용어를 알아야 해.

문법의미
async def비동기 함수 정의
await비동기 작업의 결과를 기다리면서 실행 제어권 양보
asyncioPython의 비동기 실행을 지원하는 표준 라이브러리

2-1. 일반 함수와 비동기 함수 비교

일반 Python 함수:

Python
def greet():    return "안녕하세요!"

호출하면 결과를 바로 받을 수 있어.

Python
result = greet()print(result)

반면 비동기 함수는 다음처럼 정의해.

Python
async def greet():    return "안녕하세요!"

여기서 async는 비동기 함수를 정의하기 위한 키워드야.

그런데 다음과 같이 호출하면:

Python
result = greet()

일반 함수처럼 문자열을 바로 반환하는 것이 아니야.

greet()는 먼저 코루틴 객체(coroutine object)를 반환해.

코루틴은 비동기 실행을 위해 정의한 작업을 나타내는 객체라고 생각하면 돼.

2-2. await는 무엇일까?

다음 코드를 보자.

Python
async def main():    result = await greet()    print(result)

await greet()는 코루틴의 실행 결과를 기다리는 코드야.

중요한 점은 기다리는 동안 이벤트 루프가 다른 작업을 실행할 수 있다는 거야.

단, 실행할 다른 작업이 없으면 단순히 해당 작업이 완료되기를 기다리게 돼.

2-3. asyncio.run()이란?

비동기 함수를 일반 Python 스크립트에서 실행하려면 다음과 같이 작성할 수 있어.

Python
import asyncio async def main():    print("안녕하세요!") asyncio.run(main())

asyncio.run()은 비동기 프로그램의 진입점을 실행하는 함수야.

내부적으로 이벤트 루프를 관리하고 전달한 코루틴이 완료되도록 실행해. 공식 문서 ↗

이벤트 루프(Event Loop)는 실행 가능한 비동기 작업을 관리하고, 작업이 대기 상태에 들어가면 다른 작업을 실행하도록 조정하는 역할을 해.

비동기 함수 실행 구조

일반 Python 프로그램

asyncio.run(main())

이벤트 루프

async def main()

await 비동기작업()

03

실습 ① 첫 번째 비동기 프로그램

이번 실습은 API를 사용하지 않아. Python 기본 라이브러리만으로 실행할 수 있어.

3-1. 프로젝트 준비

기존 langchain-study 폴더에 async_basic.py라는 파일을 만들어.

async_basic.py
파일 저장 ↓
import asyncio # 비동기 함수 정의async def say_hello():    print("1. 작업 시작")     await asyncio.sleep(2)     print("2. 작업 완료")     return "안녕하세요!" # 프로그램의 비동기 진입점async def main():    result = await say_hello()     print("3. 결과:", result) # 실제 프로그램 실행if __name__ == "__main__":    asyncio.run(main())

3-2. 실행하기

터미널
uv run python async_basic.py

예상 출력은 다음과 같아.

예상 결과 / 흐름
1. 작업 시작 (약 2초 후) 2. 작업 완료3. 결과: 안녕하세요!

괄호 안의 시간 설명은 이해를 위한 주석이며 실제 출력 문장은 아니야.

3-3. 코드 한 줄씩 해설

① asyncio 가져오기

Python
import asyncio

Python 표준 라이브러리인 asyncio를 가져와.

uv add asyncio 같은 패키지 설치는 필요 없어.

② 비동기 함수 정의하기

Python
async def say_hello():

async def를 사용하면 비동기 함수를 정의할 수 있어.

③ 작업 시작 출력

Python
print("1. 작업 시작")

함수가 실제 실행되기 시작하면 화면에 문자열을 출력해.

④ 비동기 대기

Python
await asyncio.sleep(2)

이 부분이 가장 중요해.

  • asyncio.sleep(2)는 약 2초 동안 비동기적으로 대기하는 작업이야.
  • await는 해당 작업이 완료되기를 기다리는 코드야.
  • 대기 중에는 이벤트 루프가 다른 실행 가능한 작업을 진행할 수 있어.

⑤ 결과 반환

Python
return "안녕하세요!"

비동기 함수도 일반 함수처럼 return을 사용할 수 있어.

⑥ main() 함수 정의

Python
async def main():    result = await say_hello()

main()도 비동기 함수로 정의했어.

await say_hello()를 실행한 다음 반환값을 result에 저장해.

⑦ 프로그램 실행

Python
if __name__ == "__main__":    asyncio.run(main())

Python 파일을 직접 실행했을 때 main() 코루틴을 실행하는 코드야.

이 패턴은 앞으로도 계속 등장하므로 익숙해지면 좋아.

04

time.sleep()과 asyncio.sleep()의 차이

비동기를 배울 때 가장 많이 헷갈리는 부분이야.

4-1. time.sleep()

Python
import time time.sleep(2)

현재 실행 중인 스레드를 약 2초 동안 멈추는 코드야.

4-2. asyncio.sleep()

Python
import asyncio await asyncio.sleep(2)

비동기 작업을 약 2초 동안 대기시키고, 이벤트 루프가 다른 작업을 실행할 기회를 줘.

구분time.sleep(2)await asyncio.sleep(2)
대기 방식현재 스레드 차단현재 코루틴 일시 중단
이벤트 루프같은 스레드의 진행을 막음다른 작업 실행 가능
주 사용 환경동기 코드비동기 코드
다른 작업 동시 진행같은 이벤트 루프에서는 방해됨가능

비동기 함수 안에서도 time.sleep()을 호출할 수는 있지만, 이벤트 루프를 막는 문제가 생길 수 있어.

따라서 지금처럼 비동기 대기를 구현할 때는 await asyncio.sleep()을 사용하는 것이 적절해. 공식 문서 ↗

05

실습 ② 순차 실행과 동시 실행 비교

이번에는 실제로 실행 시간 차이를 확인해 보자.

5-1. 전체 코드

async_compare.py 파일을 만들어.

async_compare.py
파일 저장 ↓
import asyncioimport time async def do_work(name):    print(f"{name} 시작")     await asyncio.sleep(1)     print(f"{name} 완료")     return f"{name} 결과" async def main():    # 1. 순차 실행    start = time.perf_counter()     result1 = await do_work("A")    result2 = await do_work("B")    result3 = await do_work("C")     sequential_time = time.perf_counter() - start     print("순차 결과:", [result1, result2, result3])    print(f"순차 실행 시간: {sequential_time:.2f}초")     # 2. 동시 실행    start = time.perf_counter()     results = await asyncio.gather(        do_work("A"),        do_work("B"),        do_work("C")    )     concurrent_time = time.perf_counter() - start     print("동시 결과:", results)    print(f"동시 실행 시간: {concurrent_time:.2f}초") if __name__ == "__main__":    asyncio.run(main())

5-2. 실행하기

터미널
uv run python async_compare.py

예상 출력:

예상 결과 / 흐름
A 시작A 완료B 시작B 완료C 시작C 완료순차 결과: ['A 결과', 'B 결과', 'C 결과']순차 실행 시간: 3.00초 A 시작B 시작C 시작A 완료B 완료C 완료동시 결과: ['A 결과', 'B 결과', 'C 결과']동시 실행 시간: 1.00초

실제 시간은 컴퓨터 실행 환경에 따라 조금 달라질 수 있어.

5-3. 코드 한 줄씩 해설

① 시간 측정을 위한 모듈

Python
import time

time 모듈을 가져왔어.

여기서는 sleep()이 아니라 실행 시간 측정을 위한 perf_counter()를 사용할 거야.

② 비동기 작업 함수

Python
async def do_work(name):

작업 이름을 받아서 비동기적으로 처리하는 함수야.

Python
await asyncio.sleep(1)

1초 정도 대기하는 작업을 수행해.

③ 순차 실행

Python
result1 = await do_work("A")result2 = await do_work("B")result3 = await do_work("C")

각 줄에 await가 있어.

첫 번째 작업이 완료되어야 두 번째 줄로 넘어가고, 두 번째 작업이 완료되어야 세 번째 줄로 넘어가.

비동기 함수를 사용했다고 해서 자동으로 여러 작업이 동시에 진행되는 것은 아니라는 점이 중요해.

④ 실행 시간 측정

Python
start = time.perf_counter()

현재 성능 측정용 시계 값을 가져와.

Python
sequential_time = time.perf_counter() - start

시작 시점과 현재 시점의 차이를 계산해 경과 시간을 구하는 코드야.

⑤ 문자열 출력 형식

Python
print(f"순차 실행 시간: {sequential_time:.2f}초")

여기서 :.2f는 숫자를 소수점 둘째 자리까지 표시하라는 Python 형식 지정 문법이야.

⑥ 동시 실행

Python
results = await asyncio.gather(    do_work("A"),    do_work("B"),    do_work("C"))

이번 실습의 핵심 코드야.

asyncio.gather()는 전달된 여러 비동기 작업을 동시 실행하도록 스케줄링하고, 결과를 모아서 반환해.

동시 실행이 가능한 경우 전체 대기 시간을 줄일 수 있어. 공식 문서 ↗

5-4. 실행 시간 직접 비교하기

비동기 실행 시간 시뮬레이터

순차 실행6초
동시 실행2초

모든 작업이 서로 독립적이고 대기 시간이 같으며, 동시에 시작하고 자원 제한 없이 처리할 수 있다는 가정이야. 실제 API 응답 시간이나 속도 향상을 보장하는 계산은 아니야.

06

asyncio.gather() 자세히 이해하기

이제 asyncio.gather()의 특징을 살펴보자.

6-1. 기본 형태

Python
results = await asyncio.gather(    task_a(),    task_b(),    task_c())

gather()는 여러 awaitable을 입력받아 실행하고, 결과를 리스트로 반환해.

6-2. 결과 순서는 어떻게 될까?

중요한 특징이 있어.

각 작업의 완료 순서와 관계없이 결과 리스트는 gather()에 전달한 순서를 유지해.

예를 들어:

Python
import asyncio async def job(name, delay):    await asyncio.sleep(delay)    print(name, "완료")    return name async def main():    results = await asyncio.gather(        job("A", 3),        job("B", 1),        job("C", 2)    )     print("결과:", results) asyncio.run(main())

예상 출력:

예상 결과 / 흐름
B 완료C 완료A 완료결과: ['A', 'B', 'C']

완료는 B → C → A 순서지만, 결과 리스트는 입력한 A → B → C 순서로 반환돼.

이 특징은 여러 AI 요청의 결과를 원래 질문과 정확하게 연결할 때 유용해.

6-3. gather에서 오류가 발생하면?

기본 설정에서 작업 하나가 예외를 발생시키면 await asyncio.gather(...)를 기다리는 코드에 해당 예외가 전달돼.

이때 나머지 작업들이 자동으로 모두 취소되는 것은 아니야.

오류도 결과에 포함해서 받고 싶다면 다음 옵션을 사용할 수 있어.

Python
results = await asyncio.gather(    task_a(),    task_b(),    task_c(),    return_exceptions=True)

이 경우 정상적으로 완료된 작업의 결과와 발생한 예외 객체가 결과 리스트에 함께 들어갈 수 있어. 공식 문서 ↗

실제 LLM 호출에서는 일부 요청이 실패해도 나머지 성공 결과를 확인하고 싶을 때 활용할 수 있어.

07

LangChain의 invoke()와 ainvoke() 비교

이제 Python 비동기를 실제 LangChain과 연결해 보자.

7-1. invoke() — 동기 방식

이전 강의에서 사용했던 코드야.

Python
model = ChatOpenAI(model="gpt-5.4-mini") response = model.invoke("Python 함수가 뭐야?") print(response.content)

invoke()는 모델의 응답이 반환될 때까지 현재 호출 흐름에서 기다려.

간단한 스크립트에서 한 번 질문을 보내는 경우에는 충분히 좋은 방법이야.

7-2. ainvoke() — 비동기 방식

비동기 방식은 다음과 같아.

Python
model = ChatOpenAI(model="gpt-5.4-mini") response = await model.ainvoke("Python 함수가 뭐야?") print(response.content)

가장 큰 차이는 두 가지야.

  • invoke() 대신 ainvoke()를 사용해.
  • ainvoke() 앞에 await를 붙여.

단, await는 일반적으로 async def로 정의한 비동기 함수 내부에서 사용해야 해.

LangChain의 ChatOpenAI는 ainvoke()를 지원해. 공식 문서 ↗

7-3. 두 방식 비교

비교invoke()ainvoke()
실행 방식동기비동기
호출 문법model.invoke(...)await model.ainvoke(...)
일반적인 반환 타입AIMessageAIMessage
단일 요청적합적합
독립 요청 여러 개순차 처리에 편리동시 처리에 편리
이벤트 루프직접 관리 불필요비동기 실행 환경 필요

ainvoke()라고 해서 모델 자체의 추론 능력이 좋아지거나 API 가격이 저렴해지는 것은 아니야.

또한 LangChain의 Runnable 인터페이스는 기본 비동기 구현으로 동기 메서드를 스레드에서 실행할 수도 있어. 따라서 모든 Runnable이 완전히 네이티브 비동기 방식으로 작동하는 것은 아니야. 공식 문서 ↗

실습 ④ 여러 AI 질문을 동시에 처리하기

이번에는 asyncio.gather()와 ChatOpenAI.ainvoke()를 함께 사용해 볼 거야.

실습 목표는 서로 다른 질문 세 개를 동시에 처리하는 프로그램을 만드는 거야.

API 요청이 세 번 발생하므로 이전 실습보다 총 사용량이 많을 수 있어.

9-1. 전체 코드

async_multiple_llm.py 파일을 만들어.

async_multiple_llm.py
파일 저장 ↓
import asyncioimport osfrom pathlib import Path from dotenv import load_dotenvfrom langchain_openai import ChatOpenAI env_path = Path(__file__).resolve().parent / ".env"load_dotenv(dotenv_path=env_path) if not os.getenv("OPENAI_API_KEY"):    raise RuntimeError("API 키가 없습니다.") async def main():    model = ChatOpenAI(model="gpt-5.4-mini")     # 세 개의 질문    questions = [        "Python 변수를 한 문장으로 설명해 줘.",        "Python 리스트를 한 문장으로 설명해 줘.",        "Python 딕셔너리를 한 문장으로 설명해 줘."    ]     print("세 가지 질문을 동시에 처리합니다.\n")     # 비동기 요청 동시 실행    responses = await asyncio.gather(        model.ainvoke(questions[0]),        model.ainvoke(questions[1]),        model.ainvoke(questions[2])    )     # 질문과 응답 출력    for question, response in zip(questions, responses):        print("질문:", question)        print("답변:", response.content)        print("--------------------") if __name__ == "__main__":    asyncio.run(main())

9-3. 핵심 코드 자세히 해설

① 질문 리스트 생성

print("답변:", response.content)

9-4. 중요한 주의사항

세 개의 질문을 동시에 보냈더라도 API 요청은 세 번 발생해.

동시 실행은 전체 대기 시간을 줄일 수 있는 기술이지, 여러 API 요청을 하나의 무료 요청으로 합쳐 주는 기능은 아니야.

또한 짧은 시간에 너무 많은 요청을 보내면 API 속도 제한에 걸릴 수 있어.

추가로 알아두기: abatch()

LangChain에는 비동기 작업을 여러 개 처리하기 위한 abatch()도 있어.

우리는 지금까지 다음 코드를 배웠어.

Python
answers = await asyncio.gather(    chain.ainvoke({"topic": "리스트"}),    chain.ainvoke({"topic": "딕셔너리"}))

LangChain의 abatch()를 사용하면 다음처럼 작성할 수 있어.

Python
answers = await chain.abatch([    {"topic": "리스트"},    {"topic": "딕셔너리"}])

둘 다 여러 입력을 비동기적으로 처리할 수 있어.

동시에 보낼 요청 수 제한하기

비동기는 요청 수나 비용을 줄여주는 기능이 아니야. 입력 3개를 모델에 보내면 보통 모델 요청도 3번이야. 서비스의 호출 제한과 시스템 자원을 고려해 동시 실행 수를 정하자.

Python
answers = await chain.abatch(    [{"topic": "리스트"}, {"topic": "함수"}, {"topic": "딕셔너리"}],    config={"max_concurrency": 2})

이 코드는 이미 구성된 chain과 실행 중인 비동기 함수 안에서 사용하는 핵심 부분이야. max_concurrency=2는 한 번에 진행하는 작업 수를 제한해. 결과는 입력 순서로 돌아와.

Python 함수 여러 개를 조합할 때는 asyncio.Semaphore도 사용할 수 있어. 아래 추가 실습 정답에는 API 없이 동시 실행 수를 제한하는 예제가 있어.

import asyncio async def work(name, limit):    async with limit:        print("시작:", name)        await asyncio.sleep(0.1)        print("완료:", name)        return name async def main():    limit = asyncio.Semaphore(2)    results = await asyncio.gather(*(work(name, limit) for name in ["A", "B", "C"]))    print("입력 순서 결과:", results)    try:        await asyncio.wait_for(asyncio.sleep(1), timeout=0.01)    except TimeoutError:        print("연습용 작업이 제한 시간을 넘었습니다.") if __name__ == "__main__":    asyncio.run(main())
