예제의 모델명은 gpt-5.4-mini야. 실제 호출 전에 내 계정에서 사용할 수 있는 모델인지 확인해 줘.

코드는 복사하거나 파일 저장 버튼으로 내려받아 터미널에서 실행해. 실제 모델을 호출하는 예제는 API 키와 인터넷 연결이 필요하고 사용 요금이 발생할 수 있어.

지난 2-5강에서는 다음과 같이 AI에게 메시지를 전달했어.

Python
messages = [    SystemMessage(content="너는 Python 선생님이야."),    HumanMessage(content="Python의 리스트가 뭐야?")] response = model.invoke(messages)

그런데 이 코드에는 한 가지 불편한 점이 있어.

질문 주제를 바꾸거나 AI의 역할을 변경할 때마다 메시지 내용을 직접 수정해야 한다는 거야.

예를 들어 사용자마다 다음과 같은 요청을 처리하고 싶다면?

  • Python 초보자에게 리스트를 설명하기
  • JavaScript 중급자에게 Promise를 설명하기
  • Python 고급자에게 데코레이터를 설명하기

이런 상황에서 사용하는 기능이 바로 ChatPromptTemplate이야.

01

프롬프트 템플릿이란?

1-1. 한 문장으로 이해하기

프롬프트 템플릿(Prompt Template)은 고정된 문장 구조에 변수를 넣어 다양한 프롬프트를 재사용할 수 있게 만드는 기능이야.

예를 들어 다음 문장을 보자.

예상 결과 / 흐름
너는 {language} 전문 강사야.{level} 수준의 학생에게 {topic}에 대해 설명해 줘.

여기서 중괄호 {} 안에 있는 부분이 변수야.

프롬프트 템플릿 작동 원리

템플릿: 너는 {language} 전문 강사야. {level} 수준의 학생에게 {topic}에 대해 설명해 줘.

위 선택값을 바꿔 봐. 실제 API를 호출하지 않고 문장만 바뀌는 예시야.

문장 구조는 그대로인데, 변수의 값만 변경하면 다양한 질문을 만들 수 있지?

이것이 프롬프트 템플릿의 핵심이야.

1-2. 왜 필요할까?

일반 문자열과 템플릿을 비교해 보자.

구분일반 문자열프롬프트 템플릿
내용 수정문자열을 직접 변경변수에 새로운 값 전달
재사용성낮음높음
시스템 메시지 구성직접 작성템플릿으로 구성
여러 입력값 처리직접 문자열 조합변수 치환 지원
체인 연결가능Runnable 인터페이스로 쉽게 연결

예를 들어 AI 튜터 서비스를 만든다면 사용자마다 언어, 학습 수준, 질문 주제가 다를 수 있어.

이때 프롬프트 템플릿을 사용하면 동일한 코드 구조를 재사용하면서 입력값만 변경할 수 있어.

02

Python의 f-string과 비교하기

새로운 개념을 배우기 전에 Python에서 이미 배웠던 문자열 문법부터 복습하자.

2-1. f-string 복습

Python
name = "철수"age = 20 message = f"{name}님의 나이는 {age}살입니다." print(message)

실행 결과:

예상 결과 / 흐름
철수님의 나이는 20살입니다.

f"..."는 문자열 안에 변수의 값을 넣을 수 있는 Python 문법이야.

{name}과 {age} 자리에 실제 변수값이 들어가지.

2-2. LangChain의 템플릿은 무엇이 다를까?

다음 코드를 보자.

Python
from langchain_core.prompts import ChatPromptTemplate prompt = ChatPromptTemplate.from_messages([    ("human", "{topic}에 대해 쉽게 설명해 줘.")])

여기서 중요한 점은 "{topic}..." 앞에 f가 없다는 것이야.

프롬프트를 생성하는 단계에서는 {topic}이 그대로 남아 있어.

이후 다음 코드를 실행하면:

Python
messages = prompt.format_messages(topic="Python")

LangChain이 {topic}을 "Python"으로 치환해 줘.

구분f-stringChatPromptTemplate
치환 시점Python 문자열 표현식을 평가할 때템플릿을 포맷할 때
기본 문법f"{topic}""{topic}"
입력값 전달Python 변수 참조format_messages() 또는 invoke()
주요 목적문자열 생성재사용 가능한 LLM 메시지 구성

ChatPromptTemplate은 기본적으로 Python의 {변수명}과 유사한 f-string 템플릿 문법을 사용하지만, Python의 f-string을 직접 평가하는 것은 아니야. 공식 문서 ↗

03

ChatPromptTemplate 기본 구조

3-1. ChatPromptTemplate이란?

ChatPromptTemplate은 System, Human 등의 채팅 메시지를 템플릿으로 만드는 클래스야.

핵심 메서드는 세 가지야.

메서드역할
from_messages()채팅 메시지 템플릿 만들기
format_messages()변수 치환 후 메시지 객체 리스트 생성
invoke()변수 치환 후 ChatPromptValue 객체 생성

세 번째 invoke()가 조금 낯설지?

우리는 이전 강의에서 model.invoke()를 배웠어.

그런데 이제 prompt.invoke()도 등장한 거야.

이 둘은 같은 이름의 메서드지만 실행 대상과 반환값이 달라.

두 가지 invoke()의 차이

prompt.invoke(입력값)

프롬프트 변수 치환 → ChatPromptValue 반환

API 호출 없음 · OpenAI 사용 요금 없음

model.invoke(메시지)

실제 LLM 호출 → AIMessage 반환

외부 API 통신 · 사용 요금 발생 가능

이 차이를 이해하는 것이 이번 강의에서 가장 중요해. 공식 API 문서에서도 템플릿의 invoke() 결과는 ChatPromptValue, format_messages() 결과는 메시지 리스트로 구분하고 있어. 공식 문서 ↗공식 문서 ↗공식 문서 ↗

4-4. 코드 한 줄씩 해설

① ChatPromptTemplate 가져오기

Python
from langchain_core.prompts import ChatPromptTemplate

langchain_core.prompts 모듈에서 ChatPromptTemplate 클래스를 가져오는 코드야.

langchain-core는 LangChain의 핵심 인터페이스와 구성 요소를 제공하는 패키지야.

② from_messages()로 템플릿 만들기

Python
prompt = ChatPromptTemplate.from_messages([    ("system", "너는 친절한 {language} 선생님이야."),    ("human", "{topic}에 대해 초보자에게 쉽게 설명해 줘."),])

from_messages()는 여러 메시지 표현을 받아 하나의 채팅 프롬프트 템플릿을 만드는 메서드야.

리스트 안에는 튜플 두 개가 있어.

튜플(Tuple)은 Python에서 여러 값을 하나로 묶는 자료형이야.

Python
("system", "너는 친절한 {language} 선생님이야.")

첫 번째 값인 "system"은 메시지 역할을 나타내.

두 번째 값은 실제 메시지 템플릿이야.

Python
("human", "{topic}에 대해 초보자에게 쉽게 설명해 줘.")

여기서는 사용자 메시지를 템플릿으로 정의했어.

이 두 튜플은 나중에 각각 SystemMessage, HumanMessage로 변환돼. 공식 문서 ↗

③ format_messages()로 변수 치환하기

Python
messages = prompt.format_messages(    language="Python",    topic="리스트")

format_messages()는 템플릿에 실제 값을 전달해서 메시지를 완성하는 메서드야.

language="Python"은 {language} 위치에 "Python"을 넣으라는 뜻이고, topic="리스트"는 {topic} 위치에 "리스트"를 넣으라는 뜻이야.

중요한 점은 반환값이 단순 문자열이 아니라 메시지 객체들의 리스트라는 거야.

④ 반복문으로 출력하기

Python
for message in messages:    print("타입:", type(message).__name__)    print("내용:", message.content)

for는 리스트에서 각 메시지를 하나씩 꺼내는 반복문이야.

type(message).__name__은 객체의 클래스 이름을 출력하고, message.content는 메시지 내용을 가져와.

그래서 SystemMessage와 HumanMessage가 각각 생성된 것을 확인할 수 있어.

실습 ② 같은 템플릿을 여러 번 재사용하기

이제 변수를 변경하면서 같은 프롬프트를 재사용해 보자.

prompt_reuse.py 파일을 만들어.

prompt_reuse.py
파일 저장 ↓
from langchain_core.prompts import ChatPromptTemplate prompt = ChatPromptTemplate.from_messages([    ("system", "너는 {language} 전문 강사야."),    ("human", "{level} 수준의 학생에게 {topic}에 대해 설명해 줘."),]) # 첫 번째 프롬프트first = prompt.format_messages(    language="Python",    level="초보자",    topic="함수") # 두 번째 프롬프트second = prompt.format_messages(    language="JavaScript",    level="중급자",    topic="Promise") print("=== 첫 번째 프롬프트 ===")for message in first:    print(message.content) print("\n=== 두 번째 프롬프트 ===")for message in second:    print(message.content)

예상 출력:

예상 결과 / 흐름
=== 첫 번째 프롬프트 ===너는 Python 전문 강사야.초보자 수준의 학생에게 함수에 대해 설명해 줘. === 두 번째 프롬프트 ===너는 JavaScript 전문 강사야.중급자 수준의 학생에게 Promise에 대해 설명해 줘.

이 코드에서는 프롬프트 구조를 한 번만 정의했어.

하지만 변수를 다르게 전달해서 서로 다른 메시지들을 만들었지.

프롬프트 템플릿의 가장 큰 장점이 바로 재사용성이야.

API를 호출하지 않고 메시지 구성만 연습하고 있으니 자유롭게 언어와 주제를 변경해 봐.

06

실습 ③ invoke()와 format_messages() 차이 이해하기

이 부분은 꼭 이해해야 해.

ChatPromptTemplate에는 format_messages()와 invoke()가 모두 있어. 둘 다 변수를 치환하지만 반환값이 달라.

6-1. format_messages()

먼저 기존 방식부터 살펴보자.

Python
messages = prompt.format_messages(    language="Python",    level="초보자",    topic="함수")

반환값은 다음과 같은 메시지 객체들의 리스트야.

예상 결과 / 흐름
[    SystemMessage(content="너는 Python 전문 강사야."),    HumanMessage(content="초보자 수준의 학생에게 함수에 대해 설명해 줘.")]

따라서 다음 코드가 가능해.

Python
print(type(messages).__name__)

출력:

예상 결과 / 흐름
list

6-2. invoke()

이번에는 같은 템플릿을 invoke()로 실행해 보자.

Python
prompt_value = prompt.invoke({    "language": "Python",    "level": "초보자",    "topic": "함수"})

여기서는 변수를 딕셔너리로 전달했어.

{} 안에는 "키": "값" 형태의 데이터가 들어 있지.

반환되는 것은 ChatPromptValue 객체야.

Python
print(type(prompt_value).__name__)

출력:

예상 결과 / 흐름
ChatPromptValue

ChatPromptValue는 완성된 채팅 프롬프트를 표현하는 객체이며, 내부에 메시지 목록을 가지고 있어. 공식 문서 ↗

Python
messages = prompt_value.to_messages()

6-4. 직접 실행해 보기

prompt_invoke.py 파일을 만들어.

prompt_invoke.py
파일 저장 ↓
from langchain_core.prompts import ChatPromptTemplate prompt = ChatPromptTemplate.from_messages([    ("system", "너는 {level}를 가르치는 선생님이야."),    ("human", "{topic}에 대해 쉽게 설명해 줘."),]) # 방식 1: format_messages()messages = prompt.format_messages(    level="초보자",    topic="Python 함수") print("=== format_messages() ===")print("반환 타입:", type(messages).__name__) for message in messages:    print(type(message).__name__, ":", message.content) # 방식 2: invoke()prompt_value = prompt.invoke({    "level": "초보자",    "topic": "Python 함수"}) print("\n=== invoke() ===")print("반환 타입:", type(prompt_value).__name__) # ChatPromptValue를 메시지 리스트로 변환converted = prompt_value.to_messages() for message in converted:    print(type(message).__name__, ":", message.content)

SystemMessage와 HumanMessage를 템플릿으로 만들기

이전 2-5강에서 배운 내용을 이번 강의와 연결해 보자.

7-1. 기존 메시지 객체와 템플릿의 차이

이전 강의에서는 다음처럼 작성했어.

Python
from langchain_core.messages import SystemMessage, HumanMessage messages = [    SystemMessage(content="너는 Python 선생님이야."),    HumanMessage(content="함수가 뭐야?")]

이것은 이미 내용이 확정된 메시지들이야.

반면 이번 강의의 코드는 다음과 같아.

Python
prompt = ChatPromptTemplate.from_messages([    ("system", "너는 {language} 선생님이야."),    ("human", "{topic}에 대해 알려 줘.")])

이것은 변수를 채워 넣기 전의 템플릿이야.

두 개념을 비교하면 다음과 같아.

일반 메시지 객체

내용이 확정된 메시지

SystemMessage

너는 Python 선생님이야.

바로 모델에 전달 가능

메시지 템플릿

변수가 포함된 구조

System 템플릿

너는 {language} 선생님이야.

변수를 채워 메시지 생성

여기서 초보자가 자주 하는 실수가 있어.

Python
prompt = ChatPromptTemplate.from_messages([    SystemMessage(content="너는 {language} 선생님이야.")])

이렇게 직접 생성한 SystemMessage는 이미 완성된 메시지로 취급돼. 따라서 {language}가 템플릿 변수처럼 자동 치환되지 않아.

변수 치환을 원하면 앞서 배운 튜플 방식을 사용해야 해.

초보자가 자주 하는 실수와 오류 해결

오류 ① 템플릿 변수를 누락한 경우

다음 프롬프트에는 변수가 두 개 있어.

Python
prompt = ChatPromptTemplate.from_messages([    ("system", "{language} 선생님이야."),    ("human", "{topic}에 대해 설명해 줘.")])

그런데 다음처럼 topic만 전달하면 어떻게 될까?

Python
prompt.format_messages(topic="함수")

language 변수의 값이 없으므로 일반적으로 KeyError가 발생해.

해결 방법은 필요한 변수를 모두 전달하는 거야.

Python
prompt.format_messages(    language="Python",    topic="함수")

프롬프트에서 필요한 변수 이름을 확인하고 싶다면 다음 속성을 사용할 수도 있어.

Python
print(prompt.input_variables)

예를 들어 language, topic과 같은 변수 이름들이 리스트로 표시돼.

오류 ② 변수 이름이 서로 다른 경우

템플릿에는 {topic}이라고 작성했는데:

Python
("human", "{topic}에 대해 설명해 줘.")

값을 전달할 때는 subject라고 작성했다면:

Python
prompt.format_messages(subject="함수")

변수 이름이 일치하지 않아 오류가 발생할 수 있어.

topic과 subject는 다른 변수라는 점을 기억하자.

오류 ③ 중괄호를 글자 그대로 사용하고 싶은 경우

프롬프트에 다음과 같은 JSON 예시를 넣고 싶다고 생각해 보자.

예상 결과 / 흐름
{"name": "철수"}

그런데 템플릿에서 단일 중괄호는 변수 표현으로 해석될 수 있어.

이럴 때는 중괄호를 두 번 작성해.

Python
prompt = ChatPromptTemplate.from_messages([    ("human", 'JSON 예시: {{"name": "철수"}}. 주제: {topic}')])

템플릿을 포맷하면 {{와 }}는 각각 {와 }로 표현돼.

이 규칙은 JSON 형식의 프롬프트를 작성할 때 특히 중요해.

오류 ④ Python f-string과 혼동하는 경우

다음 코드는 Python이 먼저 변수를 치환해 버려.

Python
topic = "함수" prompt = ChatPromptTemplate.from_messages([    ("human", f"{topic}를 설명해 줘.")])

이 코드 자체가 잘못된 것은 아니지만, 이미 "함수를 설명해 줘."라는 고정 문자열이 만들어지므로 템플릿으로 재사용하기 어려워.

재사용하려면 다음처럼 작성하자.

Python
prompt = ChatPromptTemplate.from_messages([    ("human", "{topic}에 대해 설명해 줘.")])
