LangChain 메시지 구조 이해하기

메시지의 역할을 이해하고 대화 내역을 유지하는 AI 만들기

권장 학습 시간60~90분
실습 안내메시지 구조 실습 무료 · 실제 API 호출 시 비용 발생
실습 전에 알아두기

예제의 모델명은 gpt-5.4-mini야. 실제 호출 전에 내 계정에서 사용할 수 있는 모델인지 확인해 줘.

코드는 복사하거나 파일 저장 버튼으로 내려받아 터미널에서 실행해. 실제 모델을 호출하는 예제는 API 키와 인터넷 연결이 필요하고 사용 요금이 발생할 수 있어.

지난 2-4강에서는 다음 코드를 작성했어.

Python
response = model.invoke("파이썬이 뭐야?")print(response.content)

이 코드로 AI에게 질문하고 답변을 받을 수 있었지.

그런데 다음과 같은 문제가 있어.

사용자: 내 이름은 철수야.

AI: 안녕하세요, 철수님\!

사용자: 내 이름이 뭐였지?

AI: 이름을 알려주지 않으셨어요.

왜 이런 일이 발생할까?

일반적인 독립 모델 호출에서는 이전 대화 내용이 다음 요청에 자동으로 포함되지 않기 때문이야.

이번 강의에서는 LangChain의 메시지 구조를 이용해 이 문제를 해결해 볼 거야.

오늘의 핵심은 다음 세 가지야.

  • SystemMessage: AI가 어떻게 행동할지 알려주는 지시문
  • HumanMessage: 사용자가 보낸 메시지
  • AIMessage: AI가 보낸 메시지

이 세 가지를 이해하면 실제 챗봇의 기본 구조를 만들 수 있어.

01

LangChain에서 메시지란?

1-1. 문자열과 메시지의 차이

이전에는 AI에게 단순히 문자열을 전달했어.

Python
model.invoke("안녕하세요!")

그런데 실제 채팅에서는 단순히 문장만 중요한 게 아니야.

누가 말했는지, 어떤 역할의 메시지인지, 어떤 순서로 대화했는지도 중요해.

그래서 LangChain에서는 메시지를 객체로 표현할 수 있어.

Python
HumanMessage(content="안녕하세요!")

이 코드는 다음 두 가지 정보를 담은 객체를 만드는 거야.

속성값
메시지 유형HumanMessage
content"안녕하세요!"

메시지 객체는 내용 외에도 ID와 기타 메타데이터를 포함할 수 있어. 공식 문서 ↗

02

SystemMessage 자세히 이해하기

2-1. SystemMessage란?

SystemMessage는 AI의 기본 행동 방식이나 역할을 설정하는 메시지야.

예를 들어 AI에게 다음과 같이 지시할 수 있어.

Python
SystemMessage(    content="너는 Python 선생님이야. 초보자에게 쉽게 설명해 줘.")

AI에게 어떤 방식으로 답변해야 하는지 알려주는 거야.

2-2. 일반 질문과 비교하기

같은 질문이라도 시스템 메시지에 따라 답변 스타일이 달라질 수 있어.

경우 A — Python 선생님

System: 너는 Python 초보자를 가르치는 선생님이야. 쉬운 비유를 사용해.

Human: 함수가 뭐야?

예상 답변: 함수는 자주 하는 작업을 버튼 하나로 실행할 수 있게 만든 작은 기계와 같아.

경우 B — 시니어 개발자

System: 너는 시니어 Python 개발자야. 간결하고 기술적으로 정확하게 답변해.

Human: 함수가 뭐야?

예상 답변: 함수는 입력을 받아 특정 로직을 수행하고 선택적으로 반환값을 제공하는 재사용 가능한 코드 단위입니다.

위 답변은 이해를 위한 예시로, 실제 AI 출력은 다를 수 있어.

핵심은 사용자가 같은 질문을 해도 시스템 메시지를 통해 AI의 응답 방식을 조정할 수 있다는 점이야.

다만 모델이 지시문을 항상 완벽하게 준수한다고 보장할 수는 없어.

2-3. 언제 사용할까?

실제 서비스에서 다음과 같은 설정을 할 때 자주 사용해.

서비스SystemMessage 예시

번역 서비스입력한 문장을 한국어로 번역해
고객센터고객 문의에 정중하고 간결하게 답변해

03

HumanMessage 자세히 이해하기

HumanMessage는 사용자 입력을 표현하는 메시지야.

가장 간단하게 작성하면 다음과 같아.

Python
HumanMessage(content="안녕하세요!")

여기서 content라는 매개변수에 실제 메시지 내용을 전달해.

이전 강의에서 사용했던 다음 코드와 비교해 보자.

Python
response = model.invoke("안녕하세요!")

일반적인 단일 텍스트 입력에서는 문자열 하나를 전달하는 것이 HumanMessage를 전달하는 간단한 방법과 비슷해.

예를 들어 다음처럼 작성할 수 있어.

Python
response = model.invoke([    HumanMessage(content="안녕하세요!")])

LangChain 공식 문서에서도 문자열 입력을 단일 사용자 메시지를 위한 축약형으로 설명하고 있어. 공식 문서 ↗

문자열과 HumanMessage 비교

문자열 방식메시지 방식
코드가 짧음역할을 명확하게 표현 가능
단순 질문에 적합여러 메시지로 구성된 대화에 적합
"안녕하세요"HumanMessage(content="안녕하세요")

처음에는 문자열이 편하지만, 앞으로 챗봇을 만들 때는 메시지 객체를 더 자주 사용하게 될 거야.

04

AIMessage 자세히 이해하기

AIMessage는 AI의 응답을 표현하는 메시지야.

우리는 이전 강의에서 이미 접해 봤어.

Python
response = model.invoke("안녕하세요!")

이때 반환되는 response가 일반적으로 AIMessage 객체야.

그런데 이번에는 우리가 직접 AIMessage를 만들어 볼 수도 있어.

Python
AIMessage(content="안녕하세요! 무엇을 도와드릴까요?")

이렇게 직접 만든 메시지는 실제 AI를 호출해서 생성한 응답이 아니야.

개발자가 이전 대화를 예시로 작성하거나, 이미 존재하는 AI 답변을 메시지 리스트에 복원할 때 사용할 수 있어.

이 차이를 꼭 기억하자.

  • model.invoke(...)가 반환한 AIMessage: 실제 모델 응답
  • AIMessage(content="...")로 만든 객체: 개발자가 작성한 메시지 객체
05

메시지 리스트(List) 이해하기

지금부터가 이번 강의의 핵심이야.

5-1. Python 리스트 복습

Python에서 리스트는 여러 값을 순서대로 저장하는 자료구조야.

예를 들어:

Python
fruits = ["사과", "바나나", "포도"] print(fruits[0])  # 사과print(fruits[1])  # 바나나

대괄호 []로 리스트를 만들고, 쉼표로 각 값을 구분해.

리스트에는 문자열뿐만 아니라 객체도 저장할 수 있어.

따라서 LangChain 메시지 객체들을 리스트에 넣을 수 있지.

Python
messages = [    SystemMessage(content="너는 Python 선생님이야."),    HumanMessage(content="변수가 뭐야?"),    AIMessage(content="변수는 값을 저장하는 이름이야."),]

이제 messages에는 메시지 객체 세 개가 들어 있어.

5-2. 메시지 리스트의 순서

메시지의 순서는 매우 중요해.

messages 리스트의 구조

전체 리스트를 모델에 전달

model.invoke(messages)

AI는 이 대화 순서를 참고해서 마지막 사용자 메시지에 답변할 수 있어.

예를 들어 마지막 질문이 "그럼 리스트는 뭐야?"라면 이전 대화를 참고해 Python의 리스트를 설명할 수 있겠지.

5-3. 리스트에서 메시지를 꺼내기

Python
print(messages[0].content)print(messages[1].content)print(messages[-1].content)

여기서:

  • [0]: 첫 번째 메시지
  • [1]: 두 번째 메시지
  • [-1]: 마지막 메시지
  • .content: 해당 메시지의 내용

특히 [-1]은 앞으로도 자주 사용할 Python 문법이야.

06

실습 ① API 없이 메시지 구조 확인하기

이번 실습은 실제 AI 모델을 호출하지 않아. 따라서 API 비용도 발생하지 않아.

6-1. 파일 만들기

기존 langchain-study 폴더에 message_basic.py 파일을 만들어.

6-2. 전체 코드

message_basic.py
파일 저장 ↓
from langchain.messages import (    SystemMessage,    HumanMessage,    AIMessage,) messages = [    SystemMessage(content="너는 Python 선생님이야."),    HumanMessage(content="Python이 뭐야?"),    AIMessage(content="Python은 배우기 쉬운 프로그래밍 언어야."),    HumanMessage(content="어디에 사용해?"),] print("=== 메시지 목록 ===") for message in messages:    print("타입:", type(message).__name__)    print("내용:", message.content)    print("------------------")

참고로 이전 강의에서 사용한 from langchain_core.messages import AIMessage도 사용할 수 있어. 이번 강의에서는 최신 LangChain 공식 문서의 langchain.messages import 방식을 사용할게. 공식 문서 ↗

6-3. 코드 한 줄씩 해설

① 메시지 클래스 가져오기

Python
from langchain.messages import (    SystemMessage,    HumanMessage,    AIMessage,)

from ... import ...는 모듈에서 필요한 클래스나 함수를 가져오는 Python 문법이야.

괄호를 사용해서 여러 클래스를 여러 줄에 나누어 작성했어.

② 메시지 리스트 생성

Python
messages = [    SystemMessage(content="너는 Python 선생님이야."),    HumanMessage(content="Python이 뭐야?"),    AIMessage(content="Python은 배우기 쉬운 프로그래밍 언어야."),    HumanMessage(content="어디에 사용해?"),]

messages라는 변수에 네 개의 메시지 객체를 저장했어.

세 번째 AIMessage는 직접 작성한 예시 응답이야. 실제 LLM이 생성한 내용은 아니야.

③ 반복문으로 메시지 확인

Python
for message in messages:

이 코드는 messages 리스트에서 값을 하나씩 가져와 message 변수에 저장하는 반복문이야.

첫 번째 반복에서는 SystemMessage 객체가, 두 번째 반복에서는 HumanMessage 객체가 들어가.

④ 메시지 타입 출력

Python
print("타입:", type(message).__name__)

type()으로 객체의 자료형을 알아내고 __name__으로 클래스 이름을 출력해.

⑤ 메시지 내용 출력

Python
print("내용:", message.content)

현재 메시지의 실제 내용을 출력하는 코드야.

6-4. 실행하기

터미널
uv run python message_basic.py
